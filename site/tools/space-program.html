Space Program Viewer

Upload 1–4 scenario exports from Parameter to view the full program, compare scenarios, and workshop edits — all locally in your browser. No data leaves your machine.

📋 How to export from Parameter
1

Open your Parameter project

Navigate to the scenario you want to export. Each scenario must be exported separately.

2

Export as Excel

Click Export → Excel (.xlsx). The file will contain sheets: Project, Program_Summary, a scenario sheet, and Glossary.

3

Upload up to 4 files here

Each file becomes one scenario tab (A, B, C, D). The scenario name is read from the Name field on the scenario sheet.

4

Use the Workshop tab

Pick any scenario as a baseline and edit quantities and unit sizes live. Export your workshop program to Excel when done.

Data privacy: All processing happens in your browser using the SheetJS library. No file content is uploaded to any server. Files are read locally and discarded when you close the tab.
